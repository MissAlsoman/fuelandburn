# PE Power-Up: The Muscle Arcade

A browser-based, student-friendly extra-credit review game for PE Weeks 7–9.

## Student directions
1. Open the GitHub Pages game link.
2. Complete all four levels: Muscle Match, Movement Mechanics, Recovery Lab, and Strength Safety.
3. Reach the PE Power-Up completion screen.
4. Take a screenshot of the completion panel.
5. Submit the screenshot in Canvas. Complete the optional reflection if requested by your teacher.

No GitHub account, download, or coding experience is needed.

## Teacher notes
- Static HTML, CSS, and JavaScript; no external libraries or student data collection.
- The game runs in the browser and can be hosted from the existing GitHub Pages site.
- Main file: `index.html`
