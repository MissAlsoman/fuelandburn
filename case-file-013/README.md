# CASE FILE #013 — What's Under the Surface?

An interactive Week 13 Health investigation for VPrepWV.

## Student experience
1. Read the case briefing.
2. Meet three fictional people.
3. Review the evidence locker.
4. Solve six interactive knowledge-check questions.
5. Complete the five-question final case report.

## Publish
This page lives at `case-file-013/index.html` in the `fuelandburn` repository. If GitHub Pages is enabled for the repository's `main` branch, the page will be available at:

`https://missalsoman.github.io/fuelandburn/case-file-013/`

The activity is self-contained (HTML, CSS, and JavaScript) and does not collect or transmit student responses. Students can print/save the final report as a PDF or take a screenshot for Canvas.

## Teacher note
This is an educational activity, not a diagnostic tool or medical advice. Review content and student directions before assigning.
