# The Great Thanksgiving Game Quest

An interactive Thanksgiving-themed Gaming Concepts Mad Lib for students.

## How it works
1. Students enter ten words in the word bank.
2. They select **Generate My Story**.
3. Their words are inserted into a silly Thanksgiving gaming adventure.
4. They can copy the story or play again with a new set of words.

## Publish with GitHub Pages
This project is saved in the `thanksgiving-madlib/` folder.

If GitHub Pages is enabled for the repository, visit:

`https://missalsoman.github.io/fuelandburn/thanksgiving-madlib/`

If Pages is not enabled yet:
1. Open the repository's **Settings**.
2. Choose **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and the **/(root)** folder, then Save.

No student accounts, downloads, or coding are required. The activity runs in the browser.
